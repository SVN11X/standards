1. Run the check (README.md, section Standard) and the tests from the repository root.
2. Fix only the errors that are green in the traffic light of `AGENTS.md`. Moving or deleting files is yellow, so list those and leave them.
3. Run the check again. When it passes, commit on a branch with a Conventional Commits message. Do not push.
4. Reply in at most ten lines: errors before, errors after, the commit, and each error you left with the reason.
