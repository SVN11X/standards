# 000. Philosophy

Read these documents in order. Each one only builds on the ones before it.

- Repositories should be easy to understand for a person and for any AI tool that arrives without context.
- Intent is written down in the repository and reviewed in pull requests. Nothing important lives only in a chat or in an agent's memory.
- Rules that matter are enforced by a check or a hook, not only by text. Text explains, mechanisms enforce.
- The owner's attention is the scarce resource. Agents batch their questions, decide what is reversible, and stop only for what is not.
- Fewer, better tools. Every third-party tool passes through the radar first.
- Plain words and English for everything inside a repository. The owner talks to agents in their own language.
